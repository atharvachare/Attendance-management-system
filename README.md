# Student Attendance Management System

A lightweight, efficient web-based solution for tracking student presence. This system simplifies the record-keeping process for educators, replacing paper logs with a streamlined digital interface built with **PHP** and **MySQL**.

---

## 🚀 Overview

The **Student Attendance Management System** is designed to help teachers and administrators manage daily attendance with ease. Whether you need to register a new student or generate a monthly report, this tool provides a centralized dashboard to handle it all.

### ✨ Key Features

* **Student Registration:** Quickly register students with essential details like name, roll number, and class.
* **Mark Attendance:** A user-friendly interface to mark students' attendance for each class or day.
* **Smart Reporting:** Generate and view detailed attendance summaries (Daily, Weekly, or Monthly).
* **Admin Panel:** Secure access to manage students, view overall attendance trends, and generate reports.
* **Responsive Design:** Fully accessible on both desktop and mobile platforms.

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL (via phpMyAdmin)
* **Web Server:** Apache (via XAMPP)

---

## ⚙️ Prerequisites

Before running the project, ensure you have the following installed:

* **XAMPP** (Apache, MySQL, PHP)
* A modern web browser (Chrome, Firefox, Edge, etc.)

---

## 🔧 Installation & Setup

1. **Clone the Repository**
```bash
git clone https://github.com/your-username/attendance-management-system.git

```


2. **Move to XAMPP htdocs**
Copy the project folder and paste it into the `htdocs` directory of your XAMPP installation.
* *Path example:* `C:\xampp\htdocs\attendance-management-system`


3. **Start Services**
Open the **XAMPP Control Panel** and start both the **Apache** and **MySQL** modules.
4. **Set Up the Database**
* Open your browser and navigate to [http://localhost/phpmyadmin/](https://www.google.com/search?q=http://localhost/phpmyadmin/).
* Create a new database named `simple_attendance_db`.
* Click on your new database and go to the **Import** tab.
* Choose the `simple_attendance_db.sql` file located inside the project's `/db` folder.
* Click **Go** to import the structure and sample data.


5. **Run the Project**
Open your browser and go to:
> `http://localhost/attendance-management-system/`
